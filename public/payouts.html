Google Drive Copy of Approved Invoices

On approval, each invoice PDF (with its bills) is saved into this folder, named like RMB-0001 - Name - 2026-11-04.pdf.

One-time setup (about 5 minutes)
  1. Signed in to the Google account that owns the folder, open script.google.com → New project.
  2. Delete what's there and paste the code below (it contains this app's secret key; keep it private).
  3. Click Deploy → New deployment, type Web app, Execute as Me, Who has access Anyone. Click Deploy and allow access when Google asks.
  4. Copy the Web app URL (ends in /exec) into the field above, paste the folder link, and save.

Already set up? To update the script (for example so cancelling can delete Drive copies): paste the new code over the old, save, then Deploy → Manage deployments → pencil icon → Version New version → Deploy. The web app link stays the same.

Cancel an Approved Invoice

For worst cases only. A cancelled invoice is removed from the payout register and can't be edited or approved again. Its number is not reused. Its uploaded bill PDFs are deleted from storage, and its Google Drive copy is moved to Drive's trash. A cancelled salary month can be invoiced again.
