    Connect the Google Sheet (admin)

    One-time setup in the sheet's Apps Script (about 5 minutes)
    1. Open the sheet, then Extensions → Apps Script. Add a new script file named InvoiceAutomator and paste the code below.
    2. Deploy → New deployment → Web app; Execute as Me, Who has access Anyone → Deploy. Allow the Gmail, Drive and Sheets access it asks for. Paste the Web app URL above and save.
    3. Click Import Config & ClientList from sheet, then check the Clients tab and the settings above.
    4. In the editor, run iyInstallTriggers once. It swaps the old timers for the new ones.
    5. Delete the old files MenuAndUI.gs, Form.html, EmailTemplate.html, Email Scheduler and ClientEmail.gs. Keep Utils.gs and the PDF extraction script.
